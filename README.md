# Princess Paint Studio V3 - Image-Based Converter

This version replaces the primitive procedural princess drawing with a real image-to-paint-by-number pipeline.

## How it works

1. Generate or download an original princess-style illustration.
2. Upload it into the app.
3. The app:
   - resizes the image
   - extracts a color palette
   - reduces colors
   - detects same-color regions
   - creates a playable paint-by-number SVG

## Why this is better

The app quality now depends on the source illustration. A good uploaded image will produce a much better-looking paint-by-number than code-generated geometric shapes.
